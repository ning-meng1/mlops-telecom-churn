# 数据泄露专项实验报告

## 一、实验概述
本实验从两个维度验证数据泄露风险：
1. **流程级泄露验证**：验证标准化、缺失值填充步骤是否存在测试集信息泄露
2. **特征级泄露扫描**：通过特征-标签相关性分析，排查目标泄露与作弊特征

实验固定随机种子：42，测试集比例：0.2

## 二、实验1：Scaler 标准化泄露验证
### 对比方案
- 方案A：使用全量数据集拟合标准化器（存在泄露风险）
- 方案B：仅使用训练集拟合标准化器（正确规范）

### 指标对比
| 指标 | 泄露方案A | 正确方案B |
|------|-----------|-----------|
| Accuracy | 0.7956 | 0.7956 |
| AUC | 0.8457 | 0.8457 |
| F1 | 0.5596 | 0.5596 |
| Precision | 0.6536 | 0.6536 |
| Recall | 0.4893 | 0.4893 |

### 实验结论
预测类别一致性：True
预测概率最大差异：0.00000000

> 当前数据集下，scaler泄露对最终结果影响极小，但属于工程规范红线，必须严格执行仅训练集fit的标准流程。
