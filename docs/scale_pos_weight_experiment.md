# scale_pos_weight 类别不平衡实验

## 1. 实验背景

Telco Customer Churn 数据集存在类别不平衡：

- 不流失（No）：5174
- 流失（Yes）：1869
- 正负样本比例约为 1:2.77

因此对 XGBoost 的 `scale_pos_weight` 进行对照实验，验证类别加权是否能够改善流失用户识别效果。

---

## 2. 实验目的

验证提高流失用户（正类，1）的训练权重后，是否能够：

1. 提高 Recall，减少真正流失用户的漏检；
2. 提高 F1；
3. 观察 Precision 是否因为误报增加而下降；
4. 判断是否有必要将类别加权方案用于正式模型。

---

## 3. 实验设计

为了保证实验公平，仅修改 `scale_pos_weight`，其他条件保持不变。

### 基线模型

```text
scale_pos_weight = 1
```
使用当前正式模型 v2。

### 实验模型
```text
scale_pos_weight = 2.7683
```
计算方式：
````text
5174 / 1869 ≈ 2.7683
````

保持以下条件不变：
```
random_state = 42
test_size = 0.2
stratify = y
learning_rate = 0.05
max_depth = 3
n_estimators = 100
```
## 4. 实验结果

````
| 指标        | v2：scale_pos_weight=1 | 加权实验：2.7683 |
| --------- | --------------------: | ----------: |
| Accuracy  |                0.7956 |      0.7431 |
| AUC       |                0.8457 |      0.8437 |
| Precision |                0.6536 |      0.5100 |
| Recall    |                0.4893 |      0.8155 |
| F1        |                0.5596 |      0.6276 |
````
## 5. 混淆矩阵

### v2：scale_pos_weight=1
````
[[938,  97],
 [191, 183]]
````
对应：
````
TN = 938
FP = 97
FN = 191
TP = 183
````
### 加权实验：scale_pos_weight=2.7683
````
[[742, 293],
 [ 69, 305]]
````
对应：
````
TN = 742
FP = 293
FN = 69
TP = 305
````
## 6. 实验分析
提高 scale_pos_weight 后：
````
Recall：0.4893 → 0.8155
F1：0.5596 → 0.6276
Precision：0.6536 → 0.5100
AUC：0.8457 → 0.8437
Accuracy：0.7956 → 0.7431
````
加权后模型明显更加重视流失用户。

真正流失用户中的漏检数量：
```
FN：191 → 69
```
说明类别加权显著降低了流失用户的漏检。

但与此同时：
```
FP：97 → 293
```
误报数量明显增加，因此 Precision 从 0.6536 降低到 0.5100。
AUC 基本没有明显变化，说明类别加权主要改变了模型的分类倾向，而没有明显改变整体排序能力。

## 7. 最终结论

本实验表明：
scale_pos_weight=2.7683 能够明显提高流失用户的 Recall 和 F1，但会牺牲 Precision 和 Accuracy。
因此 scale_pos_weight 并不是越大越好，需要结合实际业务目标进行选择。

当前项目保留 v2：
```
scale_pos_weight = 1
```
作为正式模型，不直接修改生产模型。
本次实验作为模型优化探索和面试案例进行留档。
如果业务目标更重视尽可能发现潜在流失用户，可以进一步考虑类别加权方案；如果更重视减少误报，则当前 v2 方案具有一定优势。
